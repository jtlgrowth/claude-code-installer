Set up Claude Code

One command. It installs the Claude Code CLI, the tools it needs, and the hire skill — then checks that all of it actually works.

1. Run the command for your computer

Copy the whole line, paste it into your terminal, press Enter. It will ask for nothing and take a few minutes.

Mac or Linux

Open Terminal (press ⌘ Space, type "Terminal", press Enter).

curl -fsSL https://raw.githubusercontent.com/jtlgrowth/claude-code-installer/main/install.sh | CCI_SKILLS=hire bash

Windows

Open PowerShell (press the Windows key, type "PowerShell", press Enter).

$env:CCI_SKILLS='hire'; irm https://raw.githubusercontent.com/jtlgrowth/claude-code-installer/main/install.ps1 | iex

2. Then

  1. Close the terminal and open a new one. This is not optional — the new window is what picks up the newly installed command.
  2. Type claude and press Enter.
  3. Type /login and sign in.
  4. Type /hire to check the skill loaded.

If something goes wrong

Install the three pieces by hand, in this order. Each one is independent, so start at whichever step failed.

a. Node

Download the LTS installer from nodejs.org and run it. On Mac with Homebrew: brew install node. Open a new terminal afterwards, then check with node -v — you want 20 or higher.

b. Claude Code

Anthropic's own installer, which is what the command above calls anyway:

curl -fsSL https://claude.ai/install.sh | bash

On Windows, in PowerShell:

irm https://claude.ai/install.ps1 | iex

c. The hire skill

npx skills add https://github.com/jtlgrowth/hire --skill hire

Same command on every platform. npx comes with Node, so do step (a) first.

Still stuck?

  • claude: command not found — you are in the terminal window you had open before installing. Open a new one.
  • Windows says running scripts is disabled — run Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass first, then paste the command again.
  • Anything else — send the last 20 lines of the output. The error text is the useful part; a screenshot of the whole window is not.

Rather read it before running it?

Sensible. Piping a script from the internet into your shell is a real decision, and these are short enough to read: install.sh · install.ps1. Both support a dry run that prints every command and executes none:

curl -fsSL https://raw.githubusercontent.com/jtlgrowth/claude-code-installer/main/install.sh | CCI_DRY_RUN=1 CCI_SKILLS=hire bash

Source: claude-code-installer · hire. Both MIT. Running the command again later is safe — it updates Claude Code and leaves anything you have already set up alone.
